独立双播台 0.2.4 · Windows x64 预览版

启动
1. 将整个 ZIP 解压到一个文件夹。
2. 打开文件夹中的 Dualcast Independent.exe。
3. 请保留 resources、locales、DLL 等文件，不要只复制 EXE。
无需安装 Node.js 或 OBS。已包含 Windows x64 编码器。
此包是未签名的便携目录包，不是安装程序。

画面与音频
选择一次共用画面，热播与百佳会沿用相同的预览和裁切。
百佳会共享窗口自动去除画布留白，按可见内容比例打开；热播仍为 16:9。
手动改变共享窗口比例或最大化时，画面等比铺满，可能额外裁掉边缘。
原始视频内部自带的黑边不自动识别，请在节目预览中手动裁切。
热播和百佳会页均可操作共享混音器。
刷新设备只枚举设备；设备名称未显示时，点击“授权音频输入”。
选好节目音频和麦克风后，启动混音并观察电平。
先录制本地文件，检查画面和声音，再开始真实推流。
百佳会通过纯画面窗口共享；本应用不安装虚拟摄像头或虚拟音频驱动。
会议声音需要另行配置虚拟音频线路，节目输入与会议回送使用不同线路。
不要同时把同一麦克风作为会议输入和混音回送输入，以免重复收音。

反馈问题
进入顶部“错误日志”页，点击“导出错误日志.txt”。
将导出的 TXT 连同操作步骤、发生时间和 Windows 版本一起提供给维护者。
导出包含应用状态、系统信息、错误、警告和操作记录；已对推流密钥等信息脱敏。
可另行导出 JSON 供技术排查。

验证范围
已在 macOS 开发机验证采集、裁切、录制、混音解码、共享窗口与日志导出，
并检查 Windows 包的可执行文件架构和资源完整性。
尚未进行 Windows 实机、虚拟音频驱动或真实平台双播验收。

0.2.3 修复
共享窗口去除裁切后产生的画布黑边，并同步调整内容尺寸。
观众端 DNS 解析失败后保持错误状态，不再被页面完成事件覆盖成等待视频。
音频选择列表禁用另一通道已选择的同一输入设备，避免重复收音。
设备列表没有虚拟输出时，请确认电脑已安装、启用相应虚拟音频设备。

0.2.4 修复
共享窗口按源画面实际像素输出，不再按 720p 画布降低裁切区域分辨率。
输出最长边最多 4096 像素，热播和录制仍维持原编码参数。
新增源分辨率、共享输出分辨率、像素比例及音频异常类型日志。
源窗口本身的清晰度和会议软件的压缩仍会影响观众看到的画面。

出现 Permission denied by system 时
这是系统拒绝音频采集，应用不能通过重复授权绕过系统限制。
检查 Windows 麦克风隐私设置中的设备访问、应用访问及桌面应用访问。
远程桌面用户还应检查客户端“本地资源 / 远程音频 / 设置 / 远程音频录制”，
允许从本机录制，并重新连接；服务器策略也可能限制录音重定向。
如果隐私开关不可用或被策略锁定，请由系统管理员检查权限。
确认系统录音程序能使用所选设备，再重启双播台进行授权和混音测试。
